# Contributing to UenkerLabs App Store

Thanks for considering a contribution. UenkerLabs App Store is an independent, community-facing open-source Android app initiative.

## Ways to help

- Suggest a genuinely useful Android app or feature through GitHub Issues.
- Report accessibility, usability, performance, or compatibility bugs.
- Propose improvements to the public site, docs, or future catalog.
- Submit focused pull requests with a clear description and manual verification steps.

## Principles

Keep contributions device-agnostic when possible. Do not add advertising, invasive tracking, unnecessary network calls, or undisclosed services. Discuss major architectural changes before implementation.

**Privacy:** never submit credentials, API tokens, private signing keys, personal files, user data, or screenshots containing private information. Review diffs before pushing. **Public Git commit author e-mail addresses are visible to everyone.** Use a GitHub-provided `users.noreply.github.com` author identity or another explicitly approved public role mailbox before committing, and enable GitHub's option to keep the private e-mail hidden. Do not use personal, employer or unrelated-domain e-mail addresses inadvertently. Existing Git history is not rewritten without a separate, risk-assessed approval.

**Builds and CI:** prefer local reasoning and focused checks. Avoid repeatedly running workflows without a reason. Releases should be reviewed and intentionally triggered.

## Current phase

There are currently **five publicly distributed, signed beta apps**: Calendar 0.2.0-dev, Alarm 0.1.0-dev and the standalone games Neon Bastion, Ember Atlas and Skybound Shift. Phone, SMS and the previous Arcade collection are withdrawn from the active catalog. Builds are NOT stable releases or fully device-tested.
